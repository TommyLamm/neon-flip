# 霓虹反轉 (Neon Flip)

![封面圖](./cover.png)

《霓虹反轉》(Neon Flip) 是一款極速賽博龐克重力反轉跑酷街機遊戲。單鍵掌控重力方向，在天花板與地板兩極霓虹導軌間穿梭、極限避障、觸發擦彈狂飆最高分！

---

## 遊戲特色
- **單鍵極簡操控 (One-Button)**：空白鍵、滑鼠點擊或全螢幕觸控，120ms 輸入緩衝與土狼時間（Coyote Time），落地即時反應。
- **三大賽博主題區域 (Zone System)**：
  1. `Cyber Strip`：經典高速賽博賽道，雙層霓虹發光導軌。
  2. `Neon Spire`：垂直雷射尖塔，動態上下往復伸縮的垂直雷射光柱。
  3. `Quantum Void`：微引力浮空漂移區間，低重力超長滯空翻滾。
- **稀有「幽靈稜鏡」(Ghost Prism)**：拾取後獲得全息能量護盾，可安全穿透一次尖刺或雷射致命碰撞！
- **極速衝擊感與色像差 (Visual Juice)**：雙層動態 Bloom 光暈隨速度由冰藍過渡至烈焰紫粉，高移速曲速流線 (Speed Lines)、相機微震動與色像差暗角。
- **動態多層次視差背景**：多層次視差滾動霓虹網格 (Parallax Cyber Grid) 與閃爍天際線光點。
- **連續碰撞檢測 (CCD)**：超高速子步 AABB 檢測，徹底消除任何高速穿透薄壁尖刺的邊界問題。
- **純代碼 Web Audio 聲學引擎**：零外部音訊檔案，內建 16 步進合成波 BGM 音序器與程式化音效。
- **跨平台自適應**：完整支援桌面寬螢幕與手機直向/橫向自適應視口。
